How the numbers are worked out

  1. Trend fit. Take the log of growth of $1, so a 20% fall counts the same at any point in history. Start with one straight line from the first month to the last. Add a breakpoint at the month furthest from the fit, refit straight lines between breakpoints, and repeat until R² reaches 0.99 or there are 15 segments.
  2. Segment months. A segment covers the months after its start breakpoint up to and including its end breakpoint, so each month belongs to exactly one segment.
  3. Total return = level at end ÷ level at start − 1. Annualised return = (1 + total)^(12 ÷ months) − 1, shown only for segments of 12 months or more.
  4. Volatility = standard deviation of the segment's monthly returns × √12. Max drawdown = deepest fall from a peak within the segment.
  5. Comparison uses exactly the same months for the other index, so excess total return compares like with like.
